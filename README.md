# MEGASTRATA (Minecraft 1.20.1 Forge)

**MEGASTRATA** — глобальный исследовательский мод для Minecraft (совместимый со сборкой *Integrated MC*), превращающий исследование мира в путешествие сквозь бесконечную искусственную среду высотой в **4000 блоков** (от `Y = -2000` до `Y = +2000`).

## Ключевые особенности
- **Вертикальная шкала 4000 блоков**: Полноценное измерение `megastrata:megastrata_dim` от глубинных механизмов Нулевого слоя (`-2000`) до Горизонтальных небес (`+2000`).
- **8 типов мегаструктур**:
  1. *Нескончаемый каркас* (`endless_frame`)
  2. *Город вертикального горизонта* (`vertical_city`)
  3. *Мёртвый океан* (`dead_ocean`)
  4. *Промышленный материк* (`industrial_continent`)
  5. *Биомеханический лес* (`biomech_forest`)
  6. *Горизонтальные небеса* (`horizontal_skies`)
  7. *Архив погребённых машин* (`buried_archive`)
  8. *Нулевой слой* (`zero_layer`)
- **Генерация сверху вниз**: Детерминированный планировщик секторов, система пространственных графов, библиотека модулей в 6 состояниях и 4 редкие гибридные комбинации слоёв.
- **Инфраструктура и вертикальный транспорт**: Ремонтируемые сервисные лифты, персональное страховочное снаряжение с зацепом за выступы, осушающие насосы, производственные линии и архивные терминалы.
- **Экология и атмосфера**: Существа с 8 состояниями ИИ (Обслуживающие дроны, Стенолазы, Фильтраторы), дальние визуальные силуэты и 3-слойный звуковой дизайн.
- **Быт и интеграция с горничными**: Обустройство убежищ, 3 роли для помощниц, поддержка `Forge Energy` и защита подземных биомов *Alex's Caves*.

## Как загрузить на GitHub и получить готовый `.jar`
1. Распакуйте содержимое архива в новую папку.
2. Инициализируйте Git и отправьте файлы в свой репозиторий GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: MEGASTRATA v1.0.0"
   git branch -M main
   git remote add origin https://github.com/<ваш-аккаунт>/<ваш-репозиторий>.git
   git push -u origin main
   ```
3. В репозитории уже настроен **GitHub Actions** (`.github/workflows/build.yml`): сразу после отправки кода на вкладке **Actions** автоматически запустится сборка, откуда можно скачать готовый скомпилированный файл `megastrata-1.0.0.jar`.

## Команда входа в измерение в игре
```mcfunction
/execute in megastrata:megastrata_dim run tp @s 0 120 0
```
